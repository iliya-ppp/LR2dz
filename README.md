# Домашнее задание к работе 2

## Условие задачи
Два длиной L1 и L2 движутся со скоростями V1 и V2 навстречу друг другу. Определите продолжительность их прохождения один против другого.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Задать исходные данные параметров поездов:
   - `L1` — длина первого поезда.
   - `L2` — длина второго поезда.
   - `V1` — скорость первого поезда.
   - `V2` — скорость второго поезда.
3. Вычислить время прохождения поездов один против другого:
   - `t` = (`L1` + `L2`) / (`V1` + `V2`)
4. Вывести результаты расчетов с подстановкой всех значений в текст.
5. **Конец**

## 2. Реализация программы

#include <stdio.h>
#include <locale.h>

void task4()
{
    setlocale(LC_ALL, "RUS");

    float L1, L2; // длины поездов (например, в метрах)
    float V1, V2; // скорости поездов (например, в метрах в секунду)
    float t;   // время прохождения мимо друг друга

    L1 = 90.0;  // длина первого поезда
    L2 = 50.0;   // длина второго поезда
    V1 = 20.0;   // скорость первого поезда
    V2 = 15.0;   // скорость второго поезда

    t = (L1 + L2) / (V1 + V2);

    printf("исходные данные:\n");
    printf("длина 1-го поезда = %.2f м, длина 2-го поезда = %.2f м\n", L1, L2);
    printf("скорость 1-го поезда = %.2f м/с, скорость 2-го поезда = %.2f м/с\n\n", V1, V2);

    printf("продолжительность прохождения поездов один против другого: %.2f секунд\n", t);
}

int main()
{
    task4();
}
